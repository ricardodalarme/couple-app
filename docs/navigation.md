## Overview

Navigation in this project is managed using [auto_route](https://pub.dev/packages/auto_route), which provides a type-safe, declarative routing system. This makes it easy to add, maintain, and navigate between pages as the app grows.

## Why auto_route?

- **Easy migration to Navigator 2**: auto_route supports both Navigator 1 and 2 APIs.
- **Reduced Boilerplate**: Route classes and navigation helpers are generated automatically.
- **Type Safety**: Navigation is checked at compile time.
- **Parameter Handling**: Passing data between routes is simple and type-safe.

## File Structure

All route configuration is centralized in:

```
/lib/routes/app_router.dart
/lib/routes/app_router.gr.dart (generated)
```

- `app_router.dart` defines the route tree using `AutoRoute` and imports all page widgets.
- `app_router.gr.dart` is generated by auto_route and should not be edited manually.

## Generating Route Classes

After adding or modifying routes, regenerate the route classes with:

```bash
melos gen
```

This updates `lib/routes/app_router.gr.dart` with the latest route definitions.

## Common Use Cases

### Adding a New Page/Route

1. **Annotate your page widget:**

```dart
import 'package:auto_route/auto_route.dart';

@RoutePage()
class ExamplePage extends StatelessWidget {
  @override
  Widget build(BuildContext context) => Placeholder();
}
```

2. **Add the route to `app_router.dart`:**

```dart
import 'package:flutter_bloc_starter/features/example/presentation/example_page.dart';
// ... other imports ...

@AutoRouterConfig()
class AppRouter extends RootStackRouter {
  @override
  List<AutoRoute> get routes => [
    // ... other routes ...
    AutoRoute(page: ExampleRoute.page),
  ];
}
```

3. **Regenerate the route classes:**

```bash
melos gen
```

This will create an `ExampleRoute` class in `app_router.gr.dart`.

### Navigating to a Route

Use the generated route class to navigate:

```dart
import 'package:flutter_bloc_starter/routes/app_router.dart';

context.pushRoute(ExampleRoute());
```

Or, if using auto_route's extension:

```dart
context.router.push(ExampleRoute());
```

### Routes with Parameters

1. **Add parameters to your page constructor:**

```dart
@RoutePage()
class ExamplePage extends StatelessWidget {
  const ExamplePage({
    required this.id,
    super.key,
  });

  final String id;

  @override
  Widget build(BuildContext context) => Placeholder();
}
```

2. **Regenerate the route classes:**

```bash
melos gen
```

3. **Navigate and pass parameters:**

```dart
context.pushRoute(ExampleRoute(id: '123'));
```

> For more details, see the [auto_route documentation](https://pub.dev/packages/auto_route).
